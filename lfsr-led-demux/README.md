# LFSR-driven LED selection

Course lab with `LFSR_22`, `Demux_1_To_4`, and `Demux_LFSR_Project_Top` in `src/Lab_05.v`. The project uses an LFSR state and switch inputs to route an LED signal to one of four outputs. The original Gowin project, pin constraints and timing constraint file are included.
